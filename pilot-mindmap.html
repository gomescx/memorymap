Keyboard Shortcuts (FreeMind-like)

Enter - Create sibling node | Tab - Create child node | F2 - Edit node | Delete - Delete node and its children | Esc - Cancel editing

Instructions: Click on the "Main Node" first to select it, then use the keyboard shortcuts.

Note: Deleting a node will also delete all its child nodes, but never parent nodes.

New: Use the metadata sidebar on the right to add invested time and elapsed time to each task. Sequence numbers are automatically calculated.

Auto-Sequencing: Sequence numbers are automatically assigned using simple child order (e.g., 1, 2, 1.1, 1.2, 2.1). Use the buttons above the mindmap to toggle display.

Display Controls: Use the buttons above the mindmap to show/hide sequence numbers or full metadata on nodes.

Check the browser console (F12) for debug messages.
