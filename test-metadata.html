🧪 Feature 2: Task Metadata Entry - Test Cases

Test 2.1: Assign Numeric Sequence to Each Node

Test Steps:

  1. Open pilot-mindmap.html
  2. Select the "Main Node"
  3. Check that the metadata sidebar shows on the right
  4. Enter "1" in the Sequence Number field
  5. Click "Save Changes"
  6. Create a child node with Tab
  7. Enter "2" in the Sequence Number field for the child
  8. Click "Save Changes"

Expected Result: Both nodes should save their sequence numbers and display them when selected.

Test 2.2: Enter Invested Time for Each Node

Test Steps:

  1. Select a node
  2. Enter "2.5" in the Invested Time field
  3. Click "Save Changes"
  4. Select another node and return to the first

Expected Result: The invested time should be preserved and displayed when the node is re-selected.

Test 2.3: Enter Elapsed Time for Each Node

Test Steps:

  1. Select a node
  2. Enter "3.0" in the Elapsed Time field
  3. Click "Save Changes"
  4. Select another node and return to the first

Expected Result: The elapsed time should be preserved and displayed when the node is re-selected.

Test 2.4: View/Edit All Metadata in Sidebar

Test Steps:

  1. Select any node
  2. Check that the sidebar shows: Node title, path, sequence field, invested time field, elapsed time field
  3. Enter values in all fields
  4. Click "Save Changes"
  5. Click "Reset" and verify fields return to saved values

Expected Result: All metadata should be visible and editable in the sidebar.

Test 2.5: Validation Warning (Bonus Feature)

Test Steps:

  1. Select a node
  2. Enter "5.0" in Invested Time
  3. Enter "3.0" in Elapsed Time
  4. Try to save

Expected Result: A warning should appear: "⚠️ Warning: Invested time cannot be greater than elapsed time!"
