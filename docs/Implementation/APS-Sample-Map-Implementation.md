# APS Policy Development Sample Map Implementation

## User Story Implemented
"As a user I want the sample map to reflect the table below so it's more relevant to the APS environment"

## Changes Made

### 1. Updated Sample Map Structure
The sample mindmap now reflects a realistic Australian Public Service (APS) policy development project with the following main deliverables:

- **Project Brief & Stakeholder ID** (40 hrs, 15 days)
- **Literature Review & Workshops** (120 hrs, 25 days)
- **Draft Policy Paper & Options** (160 hrs, 20 days)
- **EL2/SES Review & Endorsement** (40 hrs, 11 days)
- **Circulate Draft & Gather Feedback** (100 hrs, 20 days)
- **Finalised Policy & Approval** (60 hrs, 15 days)
- **Implementation Plan** (80 hrs, 10 days)
- **Project Report & Handover** (30 hrs, 5 days)

### 2. Added Sub-deliverables
Each main deliverable includes relevant sub-tasks:
- Stakeholder mapping, scope definition
- Academic research, workshops, best practice analysis
- Policy options, cost-benefit analysis, risk assessment
- Resource planning, communications strategy, timeline development

### 3. Metadata Integration
All deliverables include:
- **Invested Time**: Hours of effort required
- **Elapsed Time**: Calendar days for completion
- **Start Dates**: Realistic project timeline starting January 2025

### 4. Updated Branding
- Changed project name to "APS Policy Development Project"
- Updated author to "APS Team"
- Modified success messages to reflect APS context

## Data Source
The time and effort data was taken directly from the provided table in the user story, representing realistic APS project delivery timeframes.

## Testing
The implementation can be tested by:
1. Opening the mindmap in a browser
2. Clicking "Create Sample Map" button
3. Exploring the nodes to see invested/elapsed time data
4. Using the metadata display features to view the APS-specific information

## Impact
This change makes the mindmap tool more relevant for Australian Public Service users by providing realistic examples of policy development projects with appropriate timeframes and deliverables.
