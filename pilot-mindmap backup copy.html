Keyboard Shortcuts (FreeMind-like)

Enter - Create sibling node | Tab - Create child node | F2 - Edit node | Delete - Delete node and its children | Esc - Cancel editing

Instructions: Click on the "Main Node" first to select it, then use the keyboard shortcuts.

Note: Deleting a node will also delete all its child nodes, but never parent nodes.

New: Use the metadata sidebar on the right to add invested time and elapsed time to each task.

Auto-Sequencing: Sequence numbers are automatically assigned using a clockwise convention starting from 1 o'clock position (e.g., 1, 1.1, 1.2, 2, 2.1).

Metadata Display: Use the checkbox in the sidebar to show/hide metadata (sequence, invested time, elapsed time) directly on nodes.

Check the browser console (F12) for debug messages.
